# IP-Locker : Herramienta de geolocalización de Protocolos de Internet (IP).

# Funcionamiento : ![Funcionamiento](https://github.com/Rootteadoorg/IP-Locker/blob/main/iplocker.png)

# Instalación | Linux :

```bash
1. Clonar el repositorio
2. cd IP-Locker (Ir al repositorio)
3. ls (Visualizar que el IP-Locker.py esté dentro)
4. chmod +x IP-Locker.py (Dar permisos al code)
5. python3 IP-Locker.py (Para Inicar)
6. Usar y disfrutar la herramienta !!
```
